# Object Tracking System

Система компьютерного зрения для отслеживания объектов в реальном времени с использованием веб-камеры. Приложение предоставляет три различных метода обнаружения объектов и интеллектуальный трекинг.

## Возможности

- Захват видео** с веб-камеры в реальном времени
- Загрузка шаблонов** для отслеживания объектов
- Три метода обнаружения**:
  - Feature Matching (ORB) - для текстурных объектов
  - Template Matching - для точного соответствия
  - Color Detection - для объектов с distinct цветом
- Интеллектуальный трекинг** с использованием CSRT/KCF/MIL трекеров
- Ручное выделение** объектов мышью
- Визуализация процесса** с bounding boxes и информацией
- Русскоязычный интерфейс**

## Установка

### Требования
- Python 3.9+
- Веб-камера

### Установка зависимостей
```
pip install opencv-python pillow numpy
```
1. Запустите приложение:
```
python object_tracker.py
```

2. Загрузите шаблон - нажмите "Загрузить фото" и выберите изображение объекта

3. Выберите метод обнаружения из выпадающего списка

4. Запустите камеру - нажмите "Запуск"

5. Автообнаружение - система автоматически найдет объект, или

6. Ручное выделение - нарисуйте прямоугольник вокруг объекта

7. Наблюдайте за трекингом - зеленый bounding box показывает отслеживаемый объект
